Prism Codeは、ソースコードを「見て・触れて・理解する」ための次世代VSCode拡張機能です。
コードを「屈折」させて見るツール——その名の通り、コードに光を当てて本質を分解して見せます。

---

■ コアコンセプト：AI-firstの解析

ソースコードをそのままAI（Gemini / OpenAI / ローカルAI）に渡し、
制御フローの意味的な解析・説明・可視化を行います。
ts-morphによるAST解析はAIの補完・フォールバックとして共存します。

AIに渡すことで得られるもの：
- 「なぜこの分岐になるか」の自然言語説明
- 構文だけでなく意図を捉えたフロー構造
- コード変換・リファクタリング提案

---

■ 4つの差別化軸

1. 双方向（Bi-directional）同期
   - Code → Node: ソースコードの関数・ロジックを即座にノードグラフに変換
   - Node → Code: ノード上の値・ラベルを編集すると、背後の .ts/.js ファイルの
                  定数・ロジックがAIを介してリアルタイムに書き換わる
   - 文字列操作ではなくASTレベルで整合性を保った変換

2. 実行状態の「ライブ・デバッグ」可視化
   - VSCode Debug Adapter Protocolと連携し、現在実行中のノードを光らせる
   - ボトルネック関数の接続線を太く・赤く表示してパフォーマンス問題を視覚化
   - Time Travel Debugging: スライダーで過去の変数状態をノードラベルに再現

3. AIによる自動レイアウト・補完
   - サイドバーのチャット欄に自然言語で指示 → ノードが自動生成・配置
   - ノードを引き出す際、次に繋ぐべきノード（エラーハンドリング等）をAIが推奨
   - 複雑なノード群を「1つのカスタムノードにまとめて」とワンクリックで整理

4. プロジェクト特化型プリセット
   - React Hooks Visualizer: useEffect依存配列・useStateの変化を専門追跡
   - XState / State Machine連携: 状態遷移図をGUIで作りながら厳密なコードを同期生成
   - 将来的にはフレームワーク別のプリセットを拡張可能

---

■ ビュー構成

マクロビュー: プロジェクト全体の関数・ファイル依存関係を鳥瞰図で表示。
              AIによる各モジュールの概念説明付き。

ミクロビュー: 単一関数の制御フローを詳細フローチャートで表示。
              ノードクリックで元のコード行にジャンプ。
              ライブデバッグ時は変数値がリアルタイムに更新される。

■ AI対応

- Gemini API系（無料枠が大きく、初心者でも始めやすい）
- OpenAI API（GPT-4系）
- ローカルAI（Ollama等、オフライン対応）

ユーザーのニーズ・予算に応じて選択可能。

---

■ ターゲットユーザー

- プログラミング学習者: コードの流れを視覚で掴み、AIの説明で理解を深める
- コードレビュアー・新規参加者: 骨格を一瞬で把握してからコードを読む
- 教員・メンター: 図を共通言語にして直感的な説明が可能
- フロントエンド開発者: UIとロジックの関係を高速にプロトタイプ化

■ 設計思想

「コードを書く」から「デザインして構築する」へ。
ビジュアルとコードの境界を溶かし、開発の透明性を極限まで高める。
